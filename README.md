# BLAZE RANDOM

A colorful, browser-based gaming website created by Anuj.

## Root files
- index.html
- style.css
- script.js
- README.md

## Included
10 playable mini-games:
1. Target Blaster
2. Battle Drive
3. Battle Memory
4. Sky Warrior
5. Snake Arena
6. Brick Breaker
7. Coin Catch
8. Color Rush
9. Reaction Test
10. Space Shooter

Also includes:
- Stylish calculator
- MrRandom player profile
- YouTube creator section
- Road to 1 Lakh Subscribers CTA
- Responsive/mobile-friendly layout
- Local best-score storage

## Run
Open `index.html` in a browser, or upload these four files to the root of a GitHub Pages repository.

The visual theme is battle-royale/arcade inspired and uses original browser graphics rather than official game logos or copyrighted game assets.
